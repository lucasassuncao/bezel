A TUI framework for Bubble Tea v2. bezel owns the frame: resize, tabs, focus, overlays, the status row and the key legend. Your app draws what goes inside the panes, with components, effects and animations that share one theme.

The shape of an app

You draw the panes.
bezel draws the rest.

  1. Declare the screen. A tree of Columns, Rows, Fixed and Fill, resolved to rects on every resize. Collapse drops a pane below a width.
  2. Hand the shell your messages first. Overlays, the status input and every key action are its; whatever it leaves is yours.
  3. Return a body per pane. A pane missing from the map gives its space back that frame.
main.go
sh := shell.New(shell.Config{
    Layout: layout.Columns(
        layout.Fixed("list", layout.Ratio(1, 3), layout.Min(26)),
        layout.Fill("detail"),
    ).Collapse(72, "detail"),
    Tabs:    tabs,
    Theme:   theme.Resolve(theme.Mint, true),
    Title:   "my app",
    Actions: []shell.Action{shell.Help(), shell.Quit()},
})

func (m model) Update(msg tea.Msg) (tea.Model, tea.Cmd) {
    var r bezel.Result
    if m.sh, r = m.sh.Update(msg); r.Handled {
        return m, r.Cmd // resize, overlays and every action
    }
    // the messages your actions send, and the keys no action claims
}

func (m model) View() tea.View {
    return tea.NewView(m.sh.View(map[string]shell.Pane{
        "list":   {Title: "Items", Body: m.renderList},
        "detail": {Title: m.path, Body: m.renderDetail},
    }))
}

What is in the box

Everything around the panes, and most of what goes in them.

One module, no cgo, built on Bubble Tea v2 and Lip Gloss v2.

▣ The frame

A shell.Shell you embed owns resize, tabs, focus, the status row, a busy spinner, the overlay stack and the key legend.

⌨ Keys as actions

Each Action is a key, a name and what it runs. The same value drives the key, the legend and the : command palette.

▦ Layouts that collapse

Columns and rows of fixed and filling panes, with minimums, maximums and ratios. Below a width, a pane steps aside.

◐ One theme

Semantic roles, not colours. 92 presets, light and dark, and WithStyles to recolour one component without touching the rest.

✦ Motion that is a message

Tweens, springs, physics, effects and scenes run on frames that arrive as messages. BEZEL_NO_MOTION turns them off.

✓ Tested by sending keys

Every model is a value and every input a message, so a test drives the app with bezeltest.Key("tab") as the terminal would.
